\# 🔐 LockBox



A secure web-based digital secret storage system.



\## Tech Stack



\- React.js

\- Spring Boot

\- Spring Security

\- JWT

\- AES Encryption

\- MySQL

\- Spring Data JPA

\- Hibernate



\## Project Structure



\- `backend/` - Spring Boot REST API

\- `frontend/` - React.js application

\- `database/` - Database scripts

\- `docs/` - Project documentation
